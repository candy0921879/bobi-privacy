BoBi 波笔

隐私政策

更新日期：2026 年 10 月 11 日 · 适用扩展版本：0.1.0

BoBi 波笔在您授权的网页上，依据您保存的规则进行文字高亮。网页匹配和规则处理在本机完成，扩展不进行自动上传，也不提供自动跨设备同步。

一、适用范围与用途

本政策说明 BoBi 波笔 Chrome 扩展当前版本如何处理数据，以及本隐私政策网页的托管情况。扩展的用途是在用户授权的网页上，按关键词、正则表达式或动态日期匹配文字并显示高亮，帮助识别阅读和工作中的重点。

“仅在本机”不表示完全不处理数据。为完成上述功能，扩展需要处理下列网页内容、网址以及您主动建立的规则和设置。

二、扩展处理哪些数据

  • 网页文字及普通控件内容：处理授权页面中可扫描的文字，以及普通文字、搜索、电话、网址、邮箱和数字输入框的当前值、文本区域内容及选择控件的当前选项文字，用于匹配和高亮。扩展排除密码类型输入框、隐藏内容、脚本等不适合处理的区域。
  • 当前页面网址：在扩展内部用于判断网页是否可访问、是否符合规则范围，以及显示当前页面状态。精确页面匹配会使用网址中的查询参数，锚点不参与该匹配。
  • 必要运行状态：标签页和文档标识、当前网址及高亮运行摘要会用于本机运行协调，保存在运行内存中。导航、关闭标签页或权限变化时会清理相应状态；扩展不将访问过的网址积累成持久化浏览历史。
  • 您主动提供的规则：包括分类与样式名称、关键词、正则表达式、日期设置、网址条件、颜色和其他高亮设置，以及您选择导入的规则文件。

网页正文、普通输入框、查询参数或您输入的规则可能包含个人信息或敏感内容。排除密码类型输入框，并不等于能自动识别并排除所有敏感信息。请谨慎选择授权网站，不要将密码、验证码、令牌等秘密内容填写到高亮规则中。

扩展不将扫描到的网页正文或控件内容写入用户规则库，也不会主动把它们发送给开发者。您自行输入或导入的相同文字则属于您主动保存的规则内容。

三、本机存储、保留与安全边界

分类、样式、关键词、匹配和网址范围、动态日期、排列及开关状态保存在当前浏览器的 chrome.storage.local 中。扩展限制完整存储区仅由可信扩展上下文直接访问，网页内容脚本通过扩展内部消息取得当前页面所需的规则。

为保证保存一致性，扩展还会保留必要的提交标识、摘要、请求去重记录和前一有效状态。若从受支持的旧版本迁移，可能在本机保留迁移前的原始资料，其中可能包含旧规则、旧历史或旧回收站资料。它们不会因当前界面中普通的规则删除操作而全部清除。

关闭弹窗、退出浏览器或关闭全局高亮开关不会删除已保存资料。本版本没有用户可用的回收站或版本历史恢复功能；上述一致性资料和迁移原档不构成可供用户撤销删除的承诺。

本版本不为这些资料另加一层应用级加密，也不是密码保险箱。请保护设备、浏览器配置文件以及导出文件；能够访问您设备或其备份的人可能获得其中的数据。

四、导入与导出

导入由您主动选择本机文件。扩展在本机读取、校验并显示预览，经您确认后才写入当前规则库；导入不会自动上传文件。

导出由您主动发起，将当前全部或所选规则及相关分类组织生成本机下载文件。导出文件可能含有您主动输入的个人信息、关键词或网址条件，请自行妥善保管。扩展不会自动替您共享、上传或在其他设备同步这些文件。

如果您自行将文件交给其他人，或放入云盘、邮件、共享目录或设备备份，其后续处理取决于您的操作及相应服务，而非扩展自动执行的传输。

五、数据使用、传输与限制

当前版本的数据处理限于提供文字高亮、规则管理、动态日期、权限判断、本机保存和用户主动导入导出所需的功能。扩展不进行自动上传，不设开发者数据接收服务器，不提供账号同步，不包含广告、遥测或访问行为分析，也不下载或执行远端代码。

扩展不出售用户数据，不将数据交给第三方用于广告投放或画像，不为与上述单一用途无关的目的使用或转移数据，也不用于判断信用等级、信用资格或提供贷款。

这些说明针对 BoBi 扩展自身。Chrome、Chrome 网上应用店、您正在浏览的网站及您主动使用的外部服务可能依各自政策处理数据，不由 BoBi 控制。

六、权限为何需要

  • activeTab：您点击扩展按钮时，用于获取当前标签页信息、判断网址和网站访问权限，并显示当前页面的高亮状态。
  • alarms：安排动态日期更新并检查时间变化，使浏览器唤醒或扩展后台恢复后能够重新计算日期高亮。
  • storage：保存本机规则、设置以及维持保存一致性所需的资料。
  • scripting：在已授权且符合规则范围的网页中注册或注入安装包内的内容脚本，执行文字匹配、显示或移除高亮，并处理动态页面变化。
  • HTTP／HTTPS 网站访问权限：经您在 Chrome 中授权后，扩展才能在相应普通网页上自动处理文字。您可在 Chrome 的扩展设置中管理或撤销网站访问权限。Chrome 禁止扩展访问的页面不属于可处理范围。

七、查看、修改、停用与删除

您可在扩展面板查看和修改规则与设置、导出规则、停用样式或关闭全局高亮，也可通过 Chrome 管理网站授权或移除扩展。关闭全局高亮会停止高亮并保留规则，但不等于删除资料，也不保证停止所有网址、权限或运行状态检查。

确认删除样式或分类后，相应项目会从当前使用的规则库移除，不需要再点击保存。为了保存一致性及旧版迁移保护，本机仍可能保留删除前的前一有效状态或迁移原档；这不是对磁盘中所有旧副本进行彻底清除的保证。

根据 Chrome 存储文档，卸载扩展会清除该扩展的 storage.local 资料。但您主动保存的导出文件、其他目录中的副本或设备备份不会因此自动删除，应由您另行处理。上述操作不构成对所有存储介质的安全擦除承诺。

八、政策网页、联系与更新

本政策网页由 GitHub Pages 托管。您访问本网页时，GitHub 可能处理 IP 地址及必要的访问或安全日志，具体请参阅 GitHub 一般隐私声明。这与 BoBi 扩展向 GitHub 上传网页内容或高亮规则不同：扩展不会自动向本政策网站发送这些资料。

本页不包含 JavaScript、统计脚本、表单或外部图片、字体等资源；点击外部链接后，相应网站将按其自身政策运行。

如对本政策有疑问，可通过 BoBi 隐私政策公开问题区联系。该渠道公开可见，请勿提交个人资料、真实网页内容、完整规则文件、密码或其他敏感信息；仅提供理解问题所必需的非敏感说明。

政策发生变化时，会在本页更新内容及顶部日期。请按您使用的扩展版本核对适用说明。本政策不表示扩展具有尚未提供的自动通知功能。
